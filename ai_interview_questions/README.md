# AI / ML Interview Coding Exercises

10 classic coding questions that come up in ML/AI engineering and research
interviews. Each file contains:

1. The problem statement.
2. A function/class signature stub for you to implement.
3. Test cases with expected outputs you can run after implementing.

Allowed libraries: `numpy` (and pure Python). Avoid using `scikit-learn`,
`torch`, or `tensorflow` for the core logic — the point is to implement
the algorithms yourself.

Run any file with: `python <filename>.py`
